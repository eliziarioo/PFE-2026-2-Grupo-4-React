# 1. Introdução
* **Objetivo do documento:** Consolidar a visão geral, escopo, requisitos de alto nível, restrições e riscos do projeto de desenvolvimento da plataforma web integrada para a gestão das operações *One to One* e *Playmakers / PKZ*.
* **Público-alvo:** Gestores (Henrique, Pedro, Thiago, Dudu), corpo docente (professores), alunos (adultos/jovens) e pais ou responsáveis.
* **Escopo do sistema:** Plataforma web integrada com foco em experiência *Mobile First* para clientes e professores, e interface desktop dedicada à gestão administrativa e inserção de testes complexos. O sistema abrange módulos de agendamento autônomo, controle de presença, gestão financeira automatizada, relatórios de evolução física e acompanhamento de mais de 16 testes físicos parametrizados.
