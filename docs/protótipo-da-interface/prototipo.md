# Protótipo de Interface - One to One & PKZ

O protótipo de interface foi desenhado para garantir usabilidade e fluidez de navegação em qualquer tela, utilizando um design limpo e objetivo. 

A estrutura da Landing Page(Hub) funciona como um funil de conversão claro, ramificando o visitante para as duas frentes do negócio:

* **One to One:** Telas focadas em autonomia e conveniência para o público adulto.
* **PKZ:** Telas focadas em alto rendimento e prestação de contas visual para pais e alunos.

Para a área operacional, a interface foi pensada sob a estratégia de "zero digitação". A navegação prioriza botões rápidos e seleções visuais para otimizar o tempo dos professores.
